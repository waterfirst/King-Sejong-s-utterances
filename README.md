# 세종의 발화

훈민정음 해례본의 옛 자모부터 현대 한글 문장까지 혀, 입술, 성대의 움직임을 살펴보는 한국어 조음 실험실입니다.

[실험실 열기](https://waterfirst.github.io/King-Sejong-s-utterances/)

## 세종의 서문과 한글의 역사

첫 화면은 《세종어제훈민정음》 언해본의 “나랏말ᄊᆞ미”로 시작합니다. 서문 첫머리와 현대어 풀이를 읽고, 발화 시연과 창제 원리 아래에서 조선 초기·중기·후기, 일제강점기, 광복 이후의 한글 역사를 살펴볼 수 있습니다.

**사료 갤러리**에는 나신걸 한글편지, 존 로스의 한국어 교재, 《독립신문》, 조선어학회의 맞춤법 통일안과 《조선말 큰사전》, 방탄소년단의 백악관 사진이 시대순으로 놓여 있습니다. 사진을 누르면 확대되고, 각 카드에서 소장처와 이미지 이용 조건을 확인할 수 있습니다.

**[한글 학술 연구](https://waterfirst.github.io/King-Sejong-s-utterances/research.html)**에서는 한글의 설계, 세종 시대의 음운 연구, 한글 이전의 표기와 기원설, 세계 언어 계통, 컴퓨터 자판과 한국어 AI를 살펴볼 수 있습니다. 언어 지도는 Glottolog 5.3(CC BY 4.0)의 대표 언어 좌표를 사용하며, 자모 실험은 유니코드 NFC와 NFD를 비교합니다.

**[세계 언어 지도](https://waterfirst.github.io/King-Sejong-s-utterances/atlas.html)**는 Unicode CLDR 49를 바탕으로 유엔 회원국 193곳 중 선택한 언어나 문자 체계에 해당하는 나라를 파란색으로 표시합니다. 문자 지도는 국가 공용·사실상 공용 언어의 대표 문자를 보여 줍니다. 화자 수와 사용 국가 수는 별도 그래프로 보여 주며, 과거 통치국 6곳의 식민 통치와 독립 대표 사례 12건은 오늘날 국가 공적 지위에 따라 지도와 표에서 비교합니다.

한국어 교육 지도는 교육부의 2025년 기준 집계에서 **한국어를 제2외국어로 정식 채택한 24곳**을 표시합니다. 정규 초·중·고에서 한국어 교육이 이루어지는 47곳과는 집계 범위가 다릅니다. 지도 바탕은 Natural Earth의 공개 도메인 자료이며, 채택 명단은 교육부 보도자료 붙임 3을 사용했습니다.

## 훈민정음 28자

첫 화면은 해례본 「예의」의 순서대로 초성 17자와 중성 11자를 보여줍니다. 자모를 고른 뒤 **느리게 관찰**을 누르거나 시간 막대로 움직임을 멈춰 보세요. **현대 비교 듣기**를 누르면 현대 한국어 음절의 소리와 조음 모형이 함께 재생됩니다. 예를 들어 ㆁ을 고르면 ‘앙’의 받침에서 혀 뒤가 올라가는 모습을 볼 수 있습니다. 로컬 한국어 음성이 없으면 현대 비교 음절의 조음만 재생됩니다. ㆆ·ㅿ·ㆍ는 재구 모형으로 살펴봅니다.

조음 시연 아래에는 「제자해」의 자음 상형과 가획, 모음의 천지인과 초출·재출, 초성·중성·종성의 모아쓰기를 정리했습니다.

## 현대 한글 입력

1. **현대 한글 입력**을 선택하고 `같이 밥을 먹어요.`처럼 한글 단어나 문장을 입력합니다. 입력이 확정되면 기본 규칙을 적용한 예상 발음이 나타납니다.
2. **발음 속도**를 `0.5×`에서 `1.3×` 사이로 설정하고 **발음과 함께 재생**을 누릅니다. 음성과 모형이 함께 움직입니다. 재생을 멈추고 속도를 바꾼 뒤 다시 시작할 수 있습니다.
3. 한 음절을 자세히 보려면 **느리게 관찰**을 누르거나 음절 선택기와 시간 막대를 사용합니다. 관찰 모드는 음절을 2.4초에 걸쳐 보여줍니다.

| 예시 | 살펴볼 움직임 |
| --- | --- |
| `맘` | 두 입술이 닫힌 채 코로 공기가 나가고, 모음에서 입술이 열렸다가 받침에서 다시 닫힙니다. |
| `하`와 `호` | ㅎ 뒤에 성문이 좁아집니다. ㅗ에서는 혀 뒤가 올라가고 입술이 둥글어집니다. |
| `국물` | 예상 발음 [궁물]에서 받침 ㄱ이 ㅇ으로 바뀌어 공기가 코로 나갑니다. |
| `같이 밥을 먹어요.` | [가치 바블 머거요]에서 구개음화와 연음에 따른 조음 위치를 볼 수 있습니다. |

## 음성과 3D 모형

- 브라우저에서 사용할 수 있는 로컬 한국어 음성으로 문장을 연속 합성합니다. 음성이 보내는 재생 시작·종료 신호를 사용하고, 단어 경계가 제공되면 그 지점에서 애니메이션 시간을 보정합니다.
- Web Speech API는 음소별 시각을 제공하지 않습니다. 단어 안에서 혀와 입술이 움직이는 시점은 추정값입니다. 단어 경계를 제공하지 않는 브라우저에서도 재생 속도를 바탕으로 움직임을 추정합니다.
- 한국어 시스템 음성이 없으면 운영체제에서 한국어 음성을 추가한 뒤 브라우저를 다시 열어 주세요. **느리게 관찰**은 음성 없이 사용할 수 있습니다.
- 입력은 브라우저에서 처리됩니다. 3D 라이브러리를 받기 위해 jsDelivr에 연결하며, 3D 초기화에 실패하면 2D 단면으로 표시합니다.
- 이 모형은 교육용입니다. 성대 진동은 눈으로 보기 쉽게 느리게 표현하고, 예상 발음은 어절 안의 기본 규칙을 적용합니다. 문맥이나 형태소에 따라 달라지는 예외는 포함하지 않을 수 있습니다.

## 로컬 실행과 배포

저장소를 클론하고 `index.html`을 브라우저에서 엽니다. 빌드 명령이나 서버는 필요하지 않습니다.

```sh
git clone https://github.com/waterfirst/King-Sejong-s-utterances.git
cd King-Sejong-s-utterances
```

GitHub Pages는 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/ (root)**를 선택합니다. 사이트 진입점은 `index.html`입니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 입력과 재생 인터페이스, 2D 단면 |
| `styles.css` | 반응형 배치와 명암 테마 |
| `articulator.js` | Three.js 입술·혀·연구개·성대 모형 |
| `app.js` | 한글 분석, 예상 발음, 음성·조음 타이밍 |
| `gallery.js` | 사료 이미지 확대와 이전·다음 이동 |
| `world-map.svg` | 교육부 집계에 따른 제2외국어 채택 지도 |
| `research.html`, `research.js`, `research-map.svg` | 학술 연구, 대표 언어 위치 지도, 유니코드 조합 실험 |
| `atlas.html`, `atlas.js`, `atlas-data.js`, `atlas-scripts.js` | 언어와 문자 체계의 국가별 지도, 화자·국가 수 그래프, 식민 통치 이후 언어 지위 비교 |
| `ai-research.html`, `ai-*.svg` | 한국어 AI 논문 5편의 실험 해설과 수치 기반 도해 |
| `language-bias.html`, `language-bias.js` | LLM 언어 편향 연구, 다국어 성능 그래프, 지역 특화 모델 |
